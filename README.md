# Stickman Mod

Create and customize Stickman characters in Minecraft Bedrock

## Features

- Stickman character creation and customization
- Stickman entities with basic AI

## Requirements

- Minecraft Bedrock Edition 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/stickman-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric Loader

## Usage

1. Obtain the Stickman Creator item
2. Right-click to open the Stickman Creator menu
3. Customize your Stickman character
4. Spawn your Stickman character in the world

The mod does not have a configuration file. All settings are hardcoded in the source code.
